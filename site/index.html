// how i run it

    
Run like production, just smaller

    

      
TLS on everythingOne reverse proxy in front, real certificates, nothing served in plain text.

      
Admin stays insideManagement tools only answer to the local network or the VPN.

      
MonitoredEvery service has an uptime check, and the alerts only fire when something's actually down.

      
Backups get testedVerified, not assumed. A backup you haven't restored is a rumor.

      
Power-awareWhen the UPS runs low, everything shuts down gracefully, in order.

      
Written downEvery host and service has a note in Obsidian, because I won't remember.
